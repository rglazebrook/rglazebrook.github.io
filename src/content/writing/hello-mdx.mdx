This is a **draft** post. It only shows in `npm run dev` and is left out of production builds.

Regular fenced code is highlighted at build time:

```css
.button {
  background: var(--color-accent);
  color: var(--color-accent-text);
}
```

And this example is live. Edit the code and the preview updates:

<LiveCode
  client:visible
  title="A tiny counter"
  code={`
() => {
  const [count, setCount] = React.useState(0);
  return (
    <button type="button" onClick={() => setCount(count + 1)}>
      Clicked {count} {count === 1 ? "time" : "times"}
    </button>
  );
}
`}
/>
